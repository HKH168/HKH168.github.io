我的第一篇博客

欢迎来到我的博客！这是我使用 Hexo + GitHub Pages 搭建的个人博客。

关于这个博客

这个博客使用以下技术栈构建：

  • Hexo - 快速、简洁且高效的静态博客框架
  • GitHub Pages - 免费的静态网站托管服务
  • Markdown - 简洁的写作语法

如何写新文章

部署到 GitHub

写完文章后，一键部署：

  • hexo clean - 清理旧的生成文件
  • hexo g - 生成静态文件
  • hexo d - 部署到 GitHub
